# Audio decoder test fixtures

Synthesised tones for `tests/audio/decode_tests.cpp`: a 0.1 s sine wave generated by ffmpeg's `sine` source. They contain no
game audio and no recording of anything. The hygiene check (`tools/check_no_game_data.py`) allows exactly this flat directory,
lower-case names, the extensions `wav`, `flac` and `ogg`, and at most 64 KB per file.

Regenerate with `FFMPEG=/path/to/ffmpeg sh make_fixtures.sh` (ffmpeg 4.4.6 with the `flac` and `libvorbis` encoders; the
commands use `-fflags +bitexact -flags:a +bitexact -map_metadata -1`, and a second run gave identical files).
